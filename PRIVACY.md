# Privacy policy

Last updated: 2026-10-13

The "rclone" OAuth client is used by one person, its owner, with the open-source [rclone](https://rclone.org) program on the owner's own computers.

- **Data accessed.** Files and file metadata in the owner's own Google Drive, as requested by the rclone commands the owner runs.
- **Storage.** The access token and any downloaded files stay on the owner's computers. No server is operated for this client, so nothing is sent to one.
- **Sharing.** No data is shared with, sold to or transferred to anyone.
- **Other users.** The client is not offered to other people. If another Google account were ever authorized by mistake, no data from it is kept, and its access can be removed at <https://myaccount.google.com/permissions>.
- **Contact.** Open an issue in this repository.

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
