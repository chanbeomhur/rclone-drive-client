Read the [common instructions](https://github.com/chanbeomhur/research-agent-home/blob/a548c7cfe16140ceb665c3a80e87b58258d4153c/AGENTS.md) before changing this repository.

Repository differences are declared in `.copier-answers.yml`. Change answers with
`copier update --defaults --data NAME=VALUE`. Never edit the answers file manually.
Use the common repository command to update the template and GitHub settings.
Use `main` as the working branch through the existing publication owner.
No separate public reproduction branch is declared.
CI runs only for an explicit critical-owner or submission qualification.
Journal profiles apply only during submission qualification.
