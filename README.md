# rclone Drive client

This repository is the home page of a personal Google OAuth client named "rclone".

The client lets its owner run [rclone](https://rclone.org), an open-source file tool, on the owner's own computers to read and manage the owner's own Google Drive. It is not a service and it is not offered to anyone else.
